HR Workforce Analytics Dashboard: Transforming Employee Data into Strategic Insights

Project Objective:

To design and implement an interactive, data-driven HR dashboard using Excel that consolidates workforce metrics—including compensation, demographics, job satisfaction, and retention drivers—enabling leadership to optimize talent management and make informed organizational decisions.

📊 Employment type breakdown (Full-time vs. Contractor)
 👥 Gender distribution across the workforce
 🎓 Education level analysis
 😊 Job satisfaction levels
 🏢 Department-wise employee filtering
 📈 Salary trends by total working years & gender
 ⚖️ Work-life balance patterns
 🎂 Age distribution insights

 Tools used: Excel (PivotTables, PivotCharts, Slicers, Data Modeling)
